# 🤖 Semantic Chatbot

An AI‑powered chatbot designed to understand user queries using semantic similarity and intent recognition.  
It leverages natural language processing techniques to provide meaningful responses and manage tasks like reminders.

---

## 📖 Overview
- Uses **sentence embeddings** to capture the meaning of user input.  
- Performs **semantic intent recognition** to identify what the user wants.  
- Supports **automated reminder management** for productivity.  
- Designed as a lightweight, student‑friendly project showcasing AI in everyday applications.

---

## 🎯 Key Features
- Understands queries beyond keyword matching.  
- Provides context‑aware responses.  
- Manages reminders and simple tasks.  
- Demonstrates practical use of NLP and AI concepts.
